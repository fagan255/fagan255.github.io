🐍 Python

Pelajari dasar-dasar pemrograman Python untuk data science

1

Syntax, Variables, and Numbers (Sintaks, Variabel, dan Angka)

Pelajari dasar-dasar syntax Python, cara mendeklarasikan variabel, dan bekerja dengan tipe data numerik (integer dan float).

⏱️ Waktu belajar: ~15 menit | 📝 Tingkat kesulitan: Pemula
2

Strings and Lists (String dan List)

Pelajari tipe data string untuk teks dan list untuk menyimpan koleksi data, serta operasi-operasi dasar padanya.

⏱️ Waktu belajar: ~20 menit | 📝 Tingkat kesulitan: Pemula
3

Dictionaries and Pandas (Dictionary dan Pandas)

Pelajari dictionary untuk pasangan key-value dan pengenalan library Pandas yang powerful untuk manipulasi data.

⏱️ Waktu belajar: ~20 menit | 📝 Tingkat kesulitan: Menengah
4

Functions and Getting Help (Fungsi dan Bantuan)

Pelajari cara mendefinisikan dan memanggil fungsi dalam Python serta bagaimana mencari dokumentasi dan bantuan.

⏱️ Waktu belajar: ~20 menit | 📝 Tingkat kesulitan: Menengah
5

Booleans and Conditionals (Boolean dan Kondisional)

Pelajari nilai boolean (True/False), operator perbandingan, dan statement conditional (if/else) untuk kontrol logika program.

⏱️ Waktu belajar: ~20 menit | 📝 Tingkat kesulitan: Menengah
