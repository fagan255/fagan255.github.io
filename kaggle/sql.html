🗄️ Intro To SQL

Pelajari SQL dari awal untuk query dan analisis data dari database

1

Getting Started With SQL and BigQuery (Memulai dengan SQL dan BigQuery)

Pengenalan SQL dan platform BigQuery untuk query data, serta cara menulis query pertama Anda.

⏱️ Waktu belajar: ~15 menit | 📝 Tingkat kesulitan: Pemula
2

Select, From & Where (Select, From, dan Where)

Pelajari fundamentals query: SELECT untuk memilih kolom, FROM untuk mengidentifikasi tabel, dan WHERE untuk filter data.

⏱️ Waktu belajar: ~20 menit | 📝 Tingkat kesulitan: Pemula
3

Group By, Having & Count (Group By, Having, dan Count)

Pelajari cara mengelompokkan data dengan GROUP BY, filter grup dengan HAVING, dan menghitung jumlah baris dengan COUNT.

⏱️ Waktu belajar: ~20 menit | 📝 Tingkat kesulitan: Menengah
4

Order By (Pengurutan Data)

Pelajari cara mengurutkan hasil query dengan ORDER BY dalam urutan ascending atau descending.

⏱️ Waktu belajar: ~15 menit | 📝 Tingkat kesulitan: Pemula
5

As & With (Alias dan CTE)

Pelajari alias (AS) untuk menyederhanakan nama kolom dan tabel, serta Common Table Expressions (CTE) dengan WITH.

⏱️ Waktu belajar: ~20 menit | 📝 Tingkat kesulitan: Menengah
6

Joins and Unions (Join dan Union)

Pelajari cara menggabungkan data dari multiple tabel menggunakan INNER JOIN, LEFT JOIN, dan UNION.

⏱️ Waktu belajar: ~25 menit | 📝 Tingkat kesulitan: Menengah-Lanjut

📌 Tentang Kursus Intro To SQL

Kursus Intro To SQL Kaggle Learn dirancang untuk pemula yang ingin belajar querying data dari database relasional. Setiap modul mencakup konsep SQL fundamental dengan praktik langsung menggunakan BigQuery, platform query data yang powerful. Anda dapat belajar dengan kecepatan sendiri dan mendapatkan sertifikat setelah menyelesaikan semua modul.
